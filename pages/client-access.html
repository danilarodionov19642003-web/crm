Доступы в личные кабинеты

Один клиент-человек (например, «Флагман») может иметь несколько анкет (a21, a22). По email он входит в личный кабинет и видит только свои данные. Сами данные изолированы на уровне Supabase RLS — клиент не сможет увидеть админку.

Важно: создание доступа здесь — это только связка email→анкеты на нашей стороне. Сам пользователь должен быть заведён в Supabase (Dashboard → Auth → Users → Add user) с этим же email и паролем, а роль client должна быть задана сервером в app_metadata. Подробности — в SUPABASE_SETUP.md.

По этому email клиент будет логиниться в свой кабинет.
При создании нового клиента — здесь задаётся стартовый пароль (от 6 символов). Можешь скопировать его и передать клиенту. При редактировании можно оставить пустым (тогда пароль не изменится) или ввести новый — он перезапишет старый.
Отметь все анкеты, которые принадлежат этому клиенту. Например, для «Флагман» — a21 и a22.
Для справки/поиска. Сообщения отправляются по chat_id ниже.
Личный chat_id самого клиента. Используется если у конкретной анкеты ниже не задан свой контакт менеджера. Клиент должен написать боту /start — бот ответит chat_id.
Если у вас общий чат с темами по каждой анкете — введи ID группы. Затем у каждой анкеты ниже укажи topic_id темы. Узнать ID: добавь @MentoriTG_bot в группу, напиши /topic в нужной теме — бот ответит ID.
